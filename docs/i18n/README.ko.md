# HomePad for macOS

> 이 번역은 AI가 작성했으며 원어민의 검수를 받지 않았습니다. HomePad는 이 언어로도 제공됩니다. 버튼과 메뉴의 이름은 앱이 표시하는 대로 적었습니다(언어는 설정 → 일반 → 언어에서 바꿀 수 있습니다). 기준이 되는 문서는 [영어 README](../../README.md)입니다.

**쓰는 모든 것이 키 하나 거리에.** HomePad는 Mac에 없던 바로 그 런처입니다. 앱을 카테고리로 나누고, 폴더에 담고, 즐겨 쓰는 항목을 고정하고, 모든 것을 즉시 검색하며, 실행 중인 앱을 한눈에 볼 수 있습니다. 원한다면 Windows 스타일 작업 표시줄도 함께 쓸 수 있습니다.

Windows 스타일 런처입니다. 단축키를 누르면 화면 가운데에 패널이 나타나며, 위쪽에는 검색 막대(Spotlight가 쓰는 것과 같은 색인을 검색합니다), 아래쪽에는 고정한 앱의 격자가 있습니다.

HomePad는 세 가지 모드로 동작합니다. 설정 → 모드에서 자신에게 맞는 것을 고르십시오.

**작업 표시줄.** Windows의 작업 표시줄과 시작 메뉴를 그대로 재현합니다. macOS에서 Windows의 사용 경험이 그립다면 집처럼 편안할 것입니다.

![작업 표시줄 모드: 시작 버튼, 실행 중인 앱, 트레이가 있는 Windows 스타일 작업 표시줄과 그 위의 HomePad 패널](../images/mode-taskbar.webp)

**Dock + HomePad.** macOS의 ‘Dock’은 그대로 쓰고 싶지만 시작 메뉴 같은 런처가 필요한 분을 위한 모드입니다. macOS에도 앱 런처가 있지만 밋밋합니다. 앱을 자동으로 카테고리에 나눌 뿐, 카테고리를 고를 수도, 앱을 폴더로 묶을 수도, 즐겨 쓰는 항목을 고정할 수도, 원하는 대로 배치할 수도 없습니다. HomePad는 이 모든 것을 해결합니다.

![Dock + HomePad 모드: macOS Dock과 그 아이콘 위로 열리는 HomePad 패널](../images/mode-dock.webp)

**독립.** 화면 공간을 최대한 확보하려는 미니멀리스트를 위한 모드입니다. 화면을 차지하는 ‘Dock’도 작업 표시줄도 없습니다. 필요할 때마다 단축키, 이중 탭, 또는 마우스를 핫 코너로 휙 밀어서 HomePad를 불러냅니다. 패널은 가운데에 나타나며, 즐겨 쓰는 앱, 파일, 폴더, 검색, 그리고 실행 중인 앱과 그 윈도우를 모두 마음대로 다룰 수 있습니다. ‘Dock’도 Spotlight도 필요 없습니다. Mac을 한 곳에서 제어하는 것입니다. 처음에는 낯설 수 있지만, 익숙해지면 엄청나게 강력합니다.

![독립 모드: ‘Dock’도 작업 표시줄도 없이 화면 가운데에 HomePad 패널](../images/mode-standalone.webp)

## 설치

HomePad는 무료이며 Apple의 서명이 없으므로, macOS는 한 번 이를 막고 문제없음을 확인해 달라고 요청합니다. 약 5분이 걸리며 한 번만 하면 됩니다. macOS 13(Ventura) 이상이 필요하며 Apple 실리콘 Mac과 Intel Mac 모두에서 동작합니다. ([INSTALL.md](../../INSTALL.md)에 zip과 일반 디스크 이미지의 경우를 포함해 같은 단계가 글로 적혀 있습니다.)

**1. 설치 프로그램 디스크 이미지를 엽니다.** `HomePad-Installer.dmg`를 이중 클릭하십시오(HomePad를 공유해 준 사람에게서 받거나 직접 빌드합니다: `tools/make_installer_dmg.sh`, [Build and run](../../README.md#build-and-run) 참조). 윈도우에 단계가 나열되어 있습니다.

<p align="center"><img src="../images/install/01-disk-image.webp" width="520" alt="번호가 매겨진 네 단계가 나열된 설치 프로그램 디스크 이미지 윈도우"></p>

**2. Install HomePad.pkg를 이중 클릭합니다.** Mac이 열 수 없다고 알립니다. **완료**를 클릭하십시오. 휴지통으로 이동이 아닙니다.

<p align="center"><img src="../images/install/02-not-opened.webp" width="340" alt="macOS가 ‘Install HomePad.pkg’이(가) 열리지 않았다고 알리는 화면"></p>

**3. 개인정보 보호 및 보안에서 허용합니다.** 디스크 이미지 윈도우의 파란색 **개인정보 보호 및 보안 열기** 타일을 이중 클릭하십시오(또는 직접 시스템 설정 → 개인정보 보호 및 보안을 여십시오). 아래로 스크롤해 **보안**까지 내려간 다음, 설치 프로그램에 관한 메시지 옆의 **그래도 열기**를 클릭하십시오.

<p align="center"><img src="../images/install/03-privacy-security.webp" width="480" alt="시스템 설정, 개인정보 보호 및 보안: ‘Install HomePad.pkg’이(가) 차단되었으며 그래도 열기 버튼이 있는 화면"></p>

**4. 확인합니다.** 이어지는 메시지에서 **그래도 열기**를 클릭한 다음 Touch ID를 사용하거나 Mac의 암호를 입력하십시오.

**5. 설치 프로그램을 진행합니다.** 소개, 알아 둘 내용, 설치 위치(이 컴퓨터의 모든 사용자용)에서 **계속**을 클릭한 다음 **설치**를 클릭하십시오. Mac이 암호를 한 번 묻습니다. 설치 프로그램이 HomePad가 응용 프로그램 폴더에 있다고 알리면 **닫기**를 클릭하십시오.

**6. 설정 가이드.** HomePad가 스스로 열리며 환영 윈도우가 나타납니다. 세 가지 권한을 허용하고, HomePad를 여는 방법(키보드 단축키, 이중 탭, 핫 코너)을 고른 다음 **시작하기**를 클릭하십시오. 각 권한은 선택 사항이지만, 세 가지 모두 허용하면 HomePad가 가장 잘 동작합니다.

<strong>7. 권한.</strong> 위에서 아래로, 각 항목 옆의 <strong>허용…</strong>을 클릭하십시오.

- **화면 기록**(실행 중인 앱의 윈도우 미리보기). 자물쇠가 있는 메시지가 나타납니다. **시스템 설정 열기**를 클릭하고 **HomePad** 옆의 스위치를 켠 다음 **종료 후 다시 열기**를 클릭하십시오. HomePad가 자동으로 재시작되며 환영 윈도우가 돌아옵니다. macOS가 HomePad가 화면에 직접 접근해도 되는지 한 번 더 물을 수 있습니다. 그때는 **허용**을 클릭하십시오.

- <strong>손쉬운 사용</strong>(고른 윈도우로 이동하는 기능과 이중 탭 단축키). <strong>허용…</strong>을 클릭한 다음 메시지에서 <strong>시스템 설정 열기</strong>를 클릭하고 <strong>HomePad</strong> 옆의 스위치를 켜십시오(암호를 물으면 입력하십시오). 최신 macOS에서는 이 페이지의 영문 화면 이름이 <strong>Device Control and Data Access</strong>입니다.

- <strong>전체 디스크 접근 권한</strong>(문서, 데스크탑, 다운로드의 파일 찾기). <strong>허용…</strong>을 클릭하십시오. 시스템 설정이 열리고 옆에 작은 HomePad 윈도우가 나타납니다. <strong>HomePad</strong> 옆의 스위치를 켜십시오. 목록에 없으면 작은 윈도우의 아이콘을 목록으로 드래그하십시오.

<strong>8. 사용합니다.</strong> <strong>Option-스페이스</strong>(또는 고른 단축키)를 누르십시오. 위의 세 가지 모드를 포함한 나머지는 모두 설정에 있습니다. 메뉴 막대의 격자 아이콘을 오른쪽 클릭한 다음 <strong>설정…</strong>을 선택하십시오.

## 사용 방법

- **Option-스페이스**는 패널을 열고 닫습니다(설정에서 바꿀 수 있습니다). 또는 Control, Option, Command를 이중 탭하십시오(설정 → 열기, 손쉬운 사용 권한이 필요합니다).
- **핫 코너**: 설정 → 열기 → 핫 코너. 작은 화면의 네 모서리 중 아무 곳이나(하나, 여러 개 또는 전부) 클릭하십시오. 선택한 모서리에 포인터를 잠깐 두면 패널이 그 모서리에서 열리며, 닫으려면 같은 동작을 다시 하십시오. 모서리를 스치듯 지나가거나 마우스 버튼을 누른 채 드래그하면 아무 일도 일어나지 않습니다. 단축키와 이중 탭은 여전히 가운데에서 엽니다. 설정 가이드의 두 번째 단계에도 있습니다. macOS가 같은 모서리를 자체 동작에 쓰고 있으면 HomePad가 이를 알리며, 핫 코너 시트가 이미 표시된 시스템 설정 → 데스크탑 및 Dock을 여는 **macOS ‘핫 코너’ 열기…** 버튼이 나타납니다(이 버튼을 누르려면 손쉬운 사용이 필요하며, 없으면 페이지만 열립니다).
- **카테고리**: 앱은 이름이 있는 카테고리에 들어 있습니다. **필수 항목**이 맨 앞에 오며 처음 실행할 때 Dock에서 채워지고, Dock의 오른쪽 끝처럼 휴지통과 다운로드가 있는 **파일** 카테고리도 함께 만들어집니다(맨 처음 실행할 때만이며, 삭제하면 삭제된 채로 남습니다). **카테고리 추가**를 누르거나 빈 공간을 오른쪽 클릭해 직접 만든 카테고리(브라우저, 글쓰기…)를 추가하십시오. 새 카테고리에는 회색의 ‘여기에 앱 추가’ 타일이 표시됩니다. 카테고리 안에서 오른쪽 클릭하면 이름을 바꾸거나 삭제할 수 있습니다(안에 있는 모든 항목도 고정이 해제되며, 앱과 파일 자체는 건드리지 않습니다).
- <strong>파일과 폴더 추가</strong>: <strong>파일 또는 폴더 추가</strong>(머리글 링크, 오른쪽 클릭 메뉴 또는 설정), Finder에서 드래그해 넣기, 또는 검색 결과를 오른쪽 클릭 → 고정. 클릭하면 열리며, 폴더는 Finder에서 열립니다. 선택기는 사이드바(홈, 데스크탑, 문서, 다운로드, ..., 드라이브)와 휴지통을 고정하는 <strong>휴지통</strong> 항목이 있는 탐색 윈도우입니다. 사이드바의 위치(문서, 다운로드, 휴지통 ...)를 클릭하면 그 위치가 열리고 폴더도 스스로 선택되므로 <strong>추가</strong>를 바로 쓸 수 있습니다. 이 윈도우들은 패널을 가리지 않습니다. 하나를 옆으로 옮기고 그 안의 타일을 패널로 드래그하십시오. 휴지통 타일을 오른쪽 클릭하면 <strong>‘휴지통’ 비우기…</strong>가 있습니다(먼저 묻습니다. HomePad는 Dock처럼 Finder가 비우게 하므로, 처음에는 HomePad가 Finder를 제어해도 되는지 macOS가 묻습니다).
- **카테고리 순서**: 카테고리 이름 위에 포인터를 올리면 초록색으로 바뀝니다. 누르면 행 전체가 선택되고(초록색 채우기와 윤곽선), 드래그하면 행 자체가 따라오며 다른 행들은 자리를 내주려고 옆으로 비킵니다(패널은 제자리에 있습니다). 놓으면 그 자리에 놓입니다. 또는 카테고리 안에서 오른쪽 클릭해 **위로 이동** / **아래로 이동**을 선택하십시오. 무언가를 드래그하는 동안에는 호버 효과와 윈도우 미리보기가 꺼집니다. ‘필수 항목’도 옮길 수 있습니다. 새 항목의 기본 위치로 남으며 삭제할 수 없습니다. 얇은 회색 선이 카테고리를 구분합니다.
- **오른쪽 클릭으로 추가**: 카테고리 안의 빈 공간(제목, 또는 타일 사이와 뒤의 틈)을 오른쪽 클릭하면 메뉴가 *그* 카테고리에 추가합니다. ‘파일에 앱 추가…’, ‘파일에 파일 또는 폴더 추가…’와 함께 그 카테고리용 카테고리 추가, 이름 변경, 삭제, 그리고 **알파벳순 정렬**(그 카테고리의 타일을 표시된 이름의 알파벳순으로 놓습니다. 이미 그 순서이면 회색으로 표시되며, 폴더 안의 타일은 자기 순서를 유지합니다)이 나타납니다. 마지막 섹션 아래의 빈 공간은 그 섹션에 속합니다.
- **앱 추가**: 앱 추가 버튼(선택기에서 앱을 이중 클릭하면 추가하고 선택기를 닫습니다), 빈 공간 오른쪽 클릭, Finder에서 앱 드래그해 넣기(드래그 도중에 단축키를 누릅니다), 또는 검색 결과를 오른쪽 클릭 → 앱 고정.
- **폴더**(Windows 시작 메뉴처럼): 타일 하나를 다른 타일의 아이콘 한가운데로 드래그해 그 아이콘이 밝아질 때까지 0.5초 동안 그대로 두었다가 놓으십시오. 두 타일이 그 자리에서 ‘폴더’라는 이름의 폴더가 되며, 폴더 타일에는 처음 네 항목이 표시됩니다. 더 많은 타일을 폴더에 놓아 추가하십시오. 폴더를 클릭하면 패널 위에 열립니다. 이름을 클릭하면 이름을 바꾸고, 항목을 클릭하면 열며, 항목을 드래그하면 순서를 바꾸거나 폴더 밖으로 꺼낼 수 있습니다(폴더가 닫혀서 항목을 다른 타일 사이에 놓을 수 있습니다). Esc나 바깥 클릭으로 닫습니다. 항목이 하나만 남은 폴더는 그 항목으로 돌아갑니다. 폴더를 오른쪽 클릭하면 ‘폴더 이름 변경…’, ‘이동’, ‘그룹 해제’가 나타나고, 열린 폴더 안의 항목을 오른쪽 클릭하면 ‘폴더에서 제거’가 나타납니다. 타일의 가장자리(가운데가 아님) 위로 드래그하면 여전히 순서만 바뀝니다.
- **제거 / 순서 변경**: 타일을 오른쪽 클릭 → 앱 고정 해제 / 이동, 또는 타일을 드래그하십시오(카테고리 사이도 가능합니다).
- **실행 중인 앱**: 아이콘 바로 아래(이름 위)의 빨간 막대는 앱이 실행 중이라는 뜻입니다. 실행 중인 앱 위에 포인터를 올리면 각 윈도우의 썸네일이 나타납니다(최소화된 윈도우는 닫기 X 옆에 빼기 기호가 있습니다). 모든 데스크탑(Space)이 대상이며 Mission Control 순서로 나열되고, 앱의 윈도우가 둘 이상의 데스크탑에 있으면 ‘Space N’ 제목이 붙습니다. 하나를 클릭하면 바로 그곳으로 이동하고(필요하면 데스크탑을 전환합니다), 모서리의 X를 클릭하면 그 윈도우만 닫습니다(다른 데스크탑의 윈도우에도 동작합니다)(화면 기록과 손쉬운 사용이 필요하며, 화면 기록이 없으면 단순한 목록이 표시됩니다). 실행 중인 앱을 클릭하면 현재 데스크탑이 우선합니다. 거기에 보이는 윈도우가 있으면 앱이 앞으로 나오고, 거기 있는 윈도우가 모두 최소화되어 있으면 가장 최근 것이 돌아오며, 거기에 윈도우가 전혀 없을 때에만 윈도우가 있는 다른 데스크탑으로 이동합니다. **실행 중** 섹션은 실행 중인 모든 앱을 나열합니다(고정 여부와 관계없이, Dock의 실행 표시와 같습니다). 여기에 추가하거나 여기서 제거할 수는 없지만, 타일은 **그 안에서 드래그해 순서를 바꿀 수** 있습니다(하나를 옮기기 전까지는 알파벳순이며, 순서는 기억되고, 종료했다가 다시 시작한 앱도 마찬가지입니다. 타일을 다른 곳에 놓을 수는 없고, Esc를 누르거나 다른 곳에서 놓으면 제자리로 돌아갑니다. ‘실행 중’을 오른쪽 클릭 → **알파벳순 정렬**은 순서를 잊게 합니다). 섹션 자체는 이름을 바꿀 수 없지만, 제목을 드래그하거나(오른쪽 클릭 메뉴의 **위로 이동** / **아래로 이동**으로) 카테고리 사이 어디로든 옮길 수 있고, 가릴 수도 있습니다(오른쪽 클릭 → ‘실행 중’ 가리기, 다시 보이려면 설정 → 패널 → ‘실행 중’ 섹션 보기). 실행 중인 각 앱의 **최소화된 윈도우**는 그곳에서 앱의 타일 뒤에 별도의 타일로 따라올 수 있습니다. 모서리에 앱 아이콘이 있는 윈도우 그림과 윈도우 제목입니다(Dock이 보여 주는 방식과 같습니다). 하나를 클릭하면 그 윈도우가 돌아오고, 오른쪽 클릭하면 ‘복원’ 또는 ‘윈도우 닫기’가 나타납니다. 기본적으로 꺼져 있습니다. 설정 → 패널 → ‘실행 중’에 최소화된 윈도우 보기를 켜거나, ‘실행 중’을 오른쪽 클릭 → 최소화된 윈도우 보기를 선택하십시오. 패널을 열 때마다 수집됩니다(손쉬운 사용이 필요하며, 그림에는 화면 기록이 필요합니다).
- **실행 중인 앱의 메뉴**: 실행 중인 앱을 오른쪽 클릭하면 Dock과 같은 메뉴가 나타납니다. 그 앱의 윈도우(맨 앞의 것에 체크 표시, 하나를 선택하면 앞으로 나옵니다), 파일 메뉴의 ‘새로운 …’ 명령(브라우저에서는 새로운 탭, 새로운 윈도우, 새로운 개인정보 보호 윈도우), 그리고 **윈도우 닫기**(열린 윈도우가 있을 때만), **가리기**, **종료**(Option을 누르고 있으면 강제 종료입니다. 종료 후 몇 초가 지나도 실행 중인 앱에는 대신 **강제 종료**가 나타납니다. Dock과 마찬가지로 Finder에는 종료가 없습니다. 종료하면 데스크탑 아이콘이 사라지기 때문입니다)가 있습니다. 윈도우와 명령은 포인터가 타일에 닿을 때 손쉬운 사용을 통해 읽습니다.
- **파일 찾기**: 문서, 데스크탑, 다운로드의 파일은 HomePad에 **전체 디스크 접근 권한**(시스템 설정 → 개인정보 보호 및 보안)이 있어야 검색에 나타납니다. 그때까지는 결과에 스위치로 이어지는 링크가 있는 안내가 표시됩니다.
- **계산기**: `7+3`, `(2+3)*4`, `2^10`, `15%` 같은 식을 입력하면 답이 맨 위에 나타납니다. ↩ 또는 복사 버튼으로 복사합니다.
- **윈도우**: 패널의 가장자리나 모서리를 드래그하면 크기를 바꿀 수 있고(가장자리에는 넓은 잡기 영역이 있으며 크기 조절 커서가 표시됩니다), 빈 부분을 드래그하면 옮길 수 있습니다(타일 격자 자체는 제외이며, 거기서 드래그하면 타일 순서가 바뀝니다). 패널이 열릴 때마다 검색 필드에 포커스가 있으므로 바로 입력할 수 있으며, 다른 곳을 클릭한 뒤에도 다음에 누르는 키는 다시 그곳으로 들어갑니다. 설정 → 패널에는 **윈도우 크기 기억**(기본적으로 켜짐)과 **윈도우 위치 기억**(기본적으로 꺼짐)이 있습니다. 설정 톱니바퀴 옆의 ↺ 버튼은 패널을 표준 크기로 되돌리고 가운데에 놓습니다. 앱 추가와 파일 또는 폴더 추가 윈도우도 크기를 바꿀 수 있습니다(열 때는 항상 표준 크기입니다).
- 패널 왼쪽 아래의 **내 이름**을 클릭하면 시스템 설정이 내 Apple 계정으로 열립니다.
- **검색**: 그냥 입력을 시작하십시오. 앱이 먼저 나오고, 다음에 문서와 폴더, 그다음에 웹 검색이 나옵니다. 선택은 ↑ ↓, 열기는 ↩, Finder에서 보기는 ⌘↩, 지우고 닫기는 Esc입니다. ‹ 버튼이나 빈 공간 클릭으로도 앱 화면으로 돌아갑니다.

## 처음 실행

환영 윈도우가 화면 기록, 손쉬운 사용, 전체 디스크 접근 권한을 허용하고 HomePad를 여는 방법을 고르도록 안내합니다(설치 참조). 언제든 메뉴 막대 아이콘 → 설정 가이드…에서 다시 열 수 있습니다.

## 설정

설정의 도구 막대에는 여섯 개의 탭이 있습니다. **모드**, **일반**(언어, 메뉴 막대 아이콘, 로그인 시 열기, 기본값으로 재설정, 처음부터 다시), **작업 표시줄**, **열기**(단축키, 이중 탭, 핫 코너), **패널**(레이아웃, 윈도우, 항목), **권한**입니다. 마지막으로 사용한 탭에서 다시 열립니다.

- **단축키**: 버튼을 클릭하고 새 조합을 누르십시오. ⌘스페이스를 쓰려면 먼저 시스템 설정 → 키보드 → 키보드 단축키 → Spotlight에서 Spotlight의 단축키를 끄십시오.
- **단축키**: 하나를 기록하거나, 이중 탭만 쓰려면 **없음**을 선택하거나, **재설정**을 눌러 ⌥스페이스로 되돌리십시오.
- **메뉴 막대 아이콘**: 설정 → 일반에서 가릴 수 있습니다. 앱을 다시 실행하면 패널이 열립니다.
- **기본값으로 재설정**: 단축키, 이중 탭, 레이아웃, Dock 가리기, 로그인 시 열기를 되돌립니다(앱과 카테고리는 유지됩니다).
- **이중 탭**: Control, Option, Command를 두 번 탭해 엽니다.
- **행당 아이콘 수**(기본값 8, 4–10)와 **행 높이**(아이콘 행 사이의 거리, 기본값 101 pt, 85–125), **아이콘 간격**(아이콘 사이의 가로 틈, 기본값 10 pt, 0–40, 패널이 그 간격에 비해 너무 좁으면 먼저 간격이 줄고 그다음에 아이콘이 줄어듭니다): 숫자를 입력하거나 − / +를 클릭하십시오. **실행 중인 앱 보기**, **Dock에서 다시 가져오기**.
- **모드**(첫 번째 탭):
  - **독립**(기본값): 단축키, 이중 탭, 핫 코너, 메뉴 막대 아이콘으로 여는 떠 있는 패널입니다. 이 모드로 바꾸면 Dock이 가려지며, 아래의 **‘Dock’ 가리기**로 되돌릴 수 있습니다.
  - **HomePad + ‘Dock’**: Dock을 작업 표시줄로 삼는 Windows 시작 메뉴식 사용 방식입니다. 이를 고르면 Dock이 항상 표시되고(HomePad가 켠 자동 가리기든 시스템 설정의 자동 가리기든 꺼집니다), Dock에 HomePad가 없으면 추가됩니다(Dock이 한 번 재시작됩니다). Dock은 놓아 둔 위치에 그대로 있습니다. 패널은 아이콘을 클릭하든 단축키나 이중 탭을 쓰든 HomePad 아이콘 바로 옆에 열립니다(아래쪽 Dock이면 그 위에, 옆쪽 Dock이면 그 곁에, 화면 안에 들도록). 아이콘을 다시 클릭하면 닫힙니다. 핫 코너는 여전히 그 모서리에서 엽니다. HomePad가 Dock에 없거나, Dock이 가려져 있거나, 손쉬운 사용 권한이 없을 때 패널이 왜 가운데에서 열리는지는 설정에 설명이 표시됩니다.
  - **작업 표시줄**: 주 화면 아래쪽을 따라가는 Windows 스타일 작업 표시줄입니다. 시작 버튼(HomePad 아이콘), 그다음에 고정한 항목과 실행 중인 앱이 가운데에 놓입니다. 그러면 실행 중인 앱은 패널을 떠납니다. 작업 표시줄의 빈 공간을 오른쪽 클릭(**앱 추가…**, **파일 또는 폴더 추가…**)하거나 타일을 오른쪽 클릭(**작업 표시줄에 고정**, HomePad 패널에서도 가능)해 앱, 파일, 폴더를 고정하십시오. 작업 표시줄 아이콘의 메뉴에는 HomePad 자체 카테고리용 **HomePad에 고정**(또는 HomePad에서 고정 해제)도 있습니다. 또는 Finder나 HomePad 패널에서 앱, 파일, 폴더를 작업 표시줄로 드래그하십시오. 놓은 아이콘의 앞에, 빈 공간에 놓으면 끝에 고정됩니다(이미 고정된 항목은 그곳으로 옮겨지며, 패널은 자기 항목을 유지합니다). 작업 표시줄의 고정 항목은 HomePad의 카테고리와 별개인 독립된 목록입니다. 아이콘을 작업 표시줄을 따라 드래그해 순서를 바꾸십시오. **앱 아이콘**은 **가운데** 또는 **왼쪽**에 놓입니다. 가운데에 있는 동안에는 **HomePad 아이콘**을 그것들과 함께 가운데에 두거나 왼쪽에 둘 수 있습니다(앱 아이콘이 왼쪽에 있으면 HomePad 아이콘은 항상 거기 있으므로 선택 항목이 회색으로 표시됩니다). 아랍어와 페르시아어에서는 왼쪽이 오른쪽이며, Windows처럼 좌우가 뒤집힙니다. HomePad 아이콘이 왼쪽에 있으면 그 패널은 작업 표시줄 위의 왼쪽 가장자리에서 열립니다. 오른쪽에는 **네트워크**, **음량**, **배터리**, **시계**가 있으며, 각각 스위치가 있습니다. 네트워크와 배터리는 시스템 설정에서 해당 페이지를 열고(최신 macOS에서는 macOS 자체의 상태 메뉴를 바깥에서 열 수 없습니다), 음량은 슬라이더를 열며(그 위에서 스크롤하면 음량이 바뀝니다), 시계는 달력을 엽니다. 항목을 클릭하면 열거나 앞으로 가져옵니다(이미 앞에 있으면 가립니다). 실행 중인 앱 위에 포인터를 올리면 윈도우가 보이고, 오른쪽 클릭하면 메뉴가 열립니다. 설정 → 작업 표시줄 → **실행 중인 앱**(처음에는 접혀 있음)은 실행 중인 모든 앱을 **작업 표시줄에 표시** 스위치와 함께 나열합니다. 꺼 둔 앱은 실행 중인 동안 작업 표시줄에 나타나지 않습니다(그 메뉴의 **작업 표시줄에서 가리기**로도 됩니다). 고정한 항목은 항상 표시됩니다. 앱을 가려도(Cmd-H) 작업 표시줄은 바뀌지 않습니다. 패널은 작업 표시줄 위 가운데에서 열립니다. 그동안 Dock은 가려집니다. macOS는 Dock만 화면의 일부를 윈도우에서 비워 둘 수 있게 하므로, 손쉬운 사용을 통해 HomePad는 윈도우가 열리거나 크기가 바뀌거나 최대화되거나 타일 배치되어 작업 표시줄 아래에 닿으면 그 윈도우를 짧게 만듭니다(너무 짧아지면 대신 위로 옮깁니다). 그곳으로 드래그해서 옮기기만 한 윈도우는 Windows처럼 그대로 둡니다. (진짜 Dock을 작업 표시줄 아래에 두는 방식은 통하지 않았습니다. 포인터가 아이콘 위를 지나갈 때마다 이름표를 표시하기 때문입니다.) **작업 표시줄 자동으로 가리기**는 포인터가 아래쪽 가장자리에 **표시 전 지연 시간**만큼 머무를 때까지 작업 표시줄을 화면 아래로 밀어 냅니다(0–1000 ms, 기본값 300이며, 가장자리를 재빨리 지나가면 나타나지 않습니다). HomePad 패널, 팝업, 윈도우 미리보기, 메뉴가 열려 있는 동안에는 올라와 있으며, 그때 윈도우는 화면 전체를 씁니다. **시작 버튼으로만 HomePad 열기**는 단축키, 이중 탭, 핫 코너를 끕니다(메뉴 막대 아이콘은 계속 동작합니다).
- **‘Dock’ 가리기**(독립 모드에서만): 1000초의 지연으로 Dock의 자동 가리기를 켜서 Dock이 절대 나타나지 않게 합니다. 끄면 일반 Dock이 돌아옵니다.
- **로그인 시 열기**.
- **언어**(설정 → 일반, 또는 메뉴 막대 아이콘 오른쪽 클릭 → 언어): Mac과 동일, 또는 20개 언어 중 하나(아랍어, 벵골어, 중국어(간체), 영어, 필리핀어, 프랑스어, 독일어, 힌디어, 인도네시아어, 이탈리아어, 일본어, 한국어, 페르시아어, 포르투갈어(브라질), 러시아어, 스페인어, 텔루구어, 태국어, 터키어, 베트남어)이며, 현재 언어의 알파벳순으로 나열됩니다. HomePad는 새 언어로 재시작하며, 아랍어와 페르시아어는 오른쪽에서 왼쪽으로 배치됩니다. 앱, 폴더, 시스템 설정 항목의 이름은 Mac이 표시하는 그대로 남습니다.

## 권한 설정

권한을 허용하면(설정 가이드, 설정, 윈도우 미리보기 어디에서든) HomePad는 시스템 설정에서 그것이 켜지는지 지켜보다가 켜지는 즉시 다시 앞으로 나옵니다. 화면 기록과 전체 디스크 접근 권한은 보통 재시작이 필요합니다. 시스템 설정이 **종료 후 다시 열기**를 제안하면 HomePad가 종료되고 스스로 다시 시작하여 있던 윈도우를 다시 엽니다.

설정 가이드는 권한이 하나라도 없을 때만 처음 실행에서 나타납니다. 처음부터 다시 거치려면 <strong>설정 → 일반 → 처음부터 다시…</strong>를 사용하십시오. macOS가 HomePad의 권한을 회수하고, 가이드가 다시 나타나며, HomePad가 재시작됩니다(상자에 체크하면 새로 설치한 것처럼 카테고리와 설정도 지웁니다).
