# HomePad for macOS

> この翻訳はAIが書いたもので、ネイティブの方による確認は受けていません。HomePadはこの言語でも利用できます。ボタンやメニューの名前は、アプリが表示するとおりに記しています（言語は「設定 → 一般 → 言語」で変更できます）。正式な内容は[英語のREADME](../../README.md)です。

**使うものすべてが、キー一つで届く。** HomePadは、あなたのMacに足りなかったランチャーです。アプリをカテゴリに分け、フォルダにまとめ、お気に入りをピン留めし、すべてを即座に検索し、実行中のアプリを常に見渡せます。お望みなら、Windows風のタスクバーも使えます。

Windows風のランチャーです。ショートカットを押すと、画面の中央にパネルが現れます。上には検索バー（Spotlightが使うのと同じインデックスを検索します）、下にはピン留めしたアプリのグリッドが並びます。

HomePadは3つのモードで動作します。「設定 → モード」で、自分に合ったものを選んでください。

**タスクバー。** Windowsのタスクバーとスタートメニューを再現します。macOSでWindowsの使い心地が恋しいなら、わが家に帰ったように感じるはずです。

![タスクバーモード：スタートボタン、実行中のアプリ、トレイを備えたWindows風のタスクバーと、その上のHomePadのパネル](../images/mode-taskbar.webp)

**Dock + HomePad。** macOSの「Dock」を使い続けたいけれど、スタートメニュー風のランチャーが必要な方向けです。macOSには「アプリ」ランチャーがありますが、物足りません。アプリを自動でカテゴリに分類するだけで、そのカテゴリは選べず、アプリをフォルダにまとめることも、お気に入りをピン留めすることも、好きなように並べることもできません。HomePadはそれをすべて解決します。

![Dock + HomePadモード：macOSのDockと、そのアイコンの上に開くHomePadのパネル](../images/mode-dock.webp)

**スタンドアロン。** 画面の広さを最大限に使いたいミニマリスト向けです。「Dock」もタスクバーも画面を占領しません。必要なときに、ショートカットキー、ダブルタップ、またはマウスをホットコーナーへ走らせてHomePadを呼び出します。パネルは中央に現れ、お気に入りのアプリ、ファイル、フォルダ、検索、そして実行中のアプリとそのウインドウを、すべて自分の思いどおりに操作できます。「Dock」もSpotlightも必要ありません。Macを一か所から操れるのです。最初は違和感があるかもしれませんが、慣れるととてつもなく強力です。

![スタンドアロンモード：「Dock」もタスクバーもなく、画面の中央にHomePadのパネル](../images/mode-standalone.webp)

## インストール

HomePadは無料で、Appleの署名はありません。そのため、macOSは一度だけこれを止め、問題ないことの確認を求めます。所要時間は約5分で、一度だけ行えば済みます。macOS 13（Ventura）以降が必要です。Apple siliconのMacでもIntelのMacでも動作します。（[INSTALL.md](../../INSTALL.md)に、zipや通常のディスクイメージの場合も含め、同じ手順を文章で記しています。）

**1. インストーラのディスクイメージを開く。** `HomePad-Installer.dmg`をダブルクリックします（HomePadを共有してくれた人から受け取るか、自分でビルドします：`tools/make_installer_dmg.sh`、[Build and run](../../README.md#build-and-run)を参照）。ウインドウに手順が表示されます。

<p align="center"><img src="../images/install/01-disk-image.webp" width="520" alt="4つの番号付きの手順が表示されたインストーラのディスクイメージのウインドウ"></p>

**2. Install HomePad.pkgをダブルクリックする。** Macが開けないと伝えます。**完了**をクリックします。「ゴミ箱に入れる」ではありません。

<p align="center"><img src="../images/install/02-not-opened.webp" width="340" alt="macOSが「Install HomePad.pkg」は開かれませんでしたと表示している"></p>

**3. プライバシーとセキュリティで許可する。** ディスクイメージのウインドウにある青い**プライバシーとセキュリティを開く**のタイルをダブルクリックします（または、自分で「システム設定 → プライバシーとセキュリティ」を開きます）。下へスクロールして**セキュリティ**まで進み、インストーラについてのメッセージの横にある**このまま開く**をクリックします。

<p align="center"><img src="../images/install/03-privacy-security.webp" width="480" alt="システム設定のプライバシーとセキュリティ：「Install HomePad.pkg」がブロックされ、「このまま開く」ボタンが表示されている"></p>

**4. 確認する。** 続くメッセージで**このまま開く**をクリックし、Touch IDを使うかMacのパスワードを入力します。

**6. セットアップガイド。** HomePadが自動的に開き、ようこそウインドウが表示されます。3つのアクセス権を許可し、HomePadの開き方（キーボードショートカット、ダブルタップ、ホットコーナー）を選んで、**はじめる**をクリックします。どのアクセス権も任意ですが、3つすべてを許可するとHomePadが最もよく働きます。

<strong>7. アクセス権。</strong> 上から順に、それぞれの横にある<strong>許可…</strong>をクリックします。

## 使い方

- **Option-スペース**でパネルを開閉します（設定で変更できます）。または、Control、Option、Commandのいずれかをダブルタップします（設定 → 開き方、アクセシビリティのアクセス権が必要です）。
- <strong>ホットコーナー</strong>：設定 → 開き方 → ホットコーナー。小さな画面の4つの角のどれか（1つ、複数、またはすべて）をクリックします。選んだ角にポインタをしばらく置くと、その角にパネルが開きます。もう一度同じことをすると閉じます。角をさっとかすめたり、マウスのボタンを押したままドラッグしたりしても、何も起こりません。ショートカットとダブルタップは、引き続き中央で開きます。セットアップガイドの2番目のステップにもあります。macOSが同じ角を自身の操作に使っている場合はHomePadがそう伝え、<strong>macOSの“ホットコーナー”を開く…</strong>ボタンを表示します。このボタンは、ホットコーナーのシートがすでに表示された状態で「システム設定 → デスクトップとDock」を開きます（このボタンを押すにはアクセシビリティが必要です。なければページだけが開きます）。
- **カテゴリ**：アプリは名前付きのカテゴリに入ります。**よく使う項目**が最初に来て、初回起動時にあなたのDockから作られます。さらに、Dockの右端のように、ゴミ箱とダウンロードを含む**ファイル**カテゴリがあります（ごく最初の起動時のみ。削除すれば、削除されたままです）。自分のカテゴリ（ブラウザ、執筆…）は、**カテゴリを追加**、または空いている場所を右クリックして追加できます。新しいカテゴリには、グレーの「ここにアプリを追加」タイルが表示されます。カテゴリの中で右クリックすると、名前を変更したり削除したりできます（中のものもすべて固定が解除されますが、アプリやファイル自体には手を付けません）。
- <strong>ファイルとフォルダの追加</strong>：<strong>ファイルまたはフォルダを追加</strong>（見出しのリンク、右クリックメニュー、または設定）、Finderからドラッグして入れる、または検索結果を右クリック → ピン留め。クリックすると開き、フォルダはFinderで開きます。ピッカーはブラウザ型のウインドウで、サイドバー（ホーム、デスクトップ、書類、ダウンロード、…、ドライブ）と、ゴミ箱をピン留めする<strong>ゴミ箱</strong>の項目があります。サイドバーの場所（書類、ダウンロード、ゴミ箱…）をクリックすると、その場所が開き、フォルダ自体も選ばれるので、<strong>追加</strong>がすぐに使えます。これらのウインドウはパネルをふさぎません。1つを脇へどけて、その中のタイルをパネルへドラッグできます。ゴミ箱のタイルを右クリックすると<strong>“ゴミ箱”を空にする…</strong>があります（先に確認します。HomePadはDockと同様にFinderに空にさせるので、初回はHomePadがFinderを操作してよいかをmacOSが尋ねます）。
- **カテゴリの順序**：カテゴリの名前にポインタを合わせると緑色になります。押すと行全体が選択され（緑の塗りと輪郭）、ドラッグすると行そのものが付いてきて、ほかの行は場所を空けるように脇へ滑ります（パネルはその場にとどまります）。放すと、その位置に収まります。または、カテゴリの中を右クリックして**上へ移動** / **下へ移動**を選びます。何かをドラッグしている間は、ホバー効果とウインドウのプレビューはオフのままです。「よく使う項目」も移動できます。新しい項目の既定の置き場所であり続け、削除はできません。細いグレーの線がカテゴリを区切ります。
- **右クリックで追加**：カテゴリの中の空いている場所（見出し、またはタイルの間とその後ろのすき間）を右クリックすると、メニューは*そのカテゴリ*に追加します。「ファイルにアプリを追加…」、「ファイルにファイルまたはフォルダを追加…」のほか、そのカテゴリ用のカテゴリを追加、名前を変更、削除、そして**アルファベット順に並べる**（そのカテゴリのタイルを表示名のアルファベット順に並べます。すでに並んでいればグレーになります。フォルダ内のタイルは順序を保ちます）があります。最後のセクションの下の余白は、そのセクションに属します。
- **アプリの追加**：アプリを追加ボタン（ピッカーでアプリをダブルクリックすると、追加してピッカーを閉じます）、空いている場所の右クリック、Finderからアプリをドラッグして入れる（ドラッグの途中でショートカットを押します）、または検索結果を右クリック → アプリをピン留め。
- **フォルダ**（Windowsのスタートメニューと同じ）：タイルを別のタイルのアイコンの真ん中にドラッグし、そのアイコンが光るまで0.5秒ほど保持して放します。2つはその場所で「フォルダ」という名前のフォルダになり、そのタイルには最初の4つの項目が表示されます。さらにタイルをフォルダに落とすと追加されます。フォルダをクリックすると、パネルの上に開きます。名前をクリックすると名前を変更でき、項目をクリックすると開き、項目をドラッグすると並べ替えたりフォルダの外へ出したりできます（フォルダが閉じるので、項目をほかのタイルの間に落とせます）。Escまたは外側のクリックで閉じます。項目が1つだけ残ったフォルダは、その項目に戻ります。フォルダを右クリックすると「フォルダの名前を変更…」、「移動先」、「グループ解除」があり、開いたフォルダ内の項目を右クリックすると「フォルダから削除」があります。タイルの端（真ん中ではなく）の上でドラッグしたときは、これまでどおり並べ替えるだけです。
- **削除 / 並べ替え**：タイルを右クリック → アプリの固定を解除 / 移動先、またはタイルをドラッグします（カテゴリ間も可）。
- **実行中のアプリ**：アイコンのすぐ下（名前の上）にある赤いバーは、そのアプリが実行中であることを示します。実行中のアプリにポインタを合わせると、各ウインドウのサムネールが表示されます（しまわれたウインドウは、閉じるバツの横にマイナスが付きます）。すべてのデスクトップ（Space）が対象で、Mission Controlの順に並び、アプリのウインドウが複数のデスクトップにある場合は「Space N」というタイトルが付きます。どれかをクリックすると直接そこへジャンプし（必要ならデスクトップを切り替えます）、角のバツをクリックするとそのウインドウだけを閉じます（ほかのデスクトップのウインドウにも使えます）（画面収録とアクセシビリティが必要です。画面収録がなければ、単純なリストになります）。実行中のアプリをクリックすると、現在のデスクトップが優先されます。そこに表示されているウインドウがあれば、アプリが前面に出ます。そこのウインドウがすべてしまわれていれば、最新のものが戻ります。そこにウインドウがまったくない場合にのみ、ウインドウのある別のデスクトップへ移動します。**実行中**セクションは、実行中のすべてのアプリを一覧にします（ピン留めの有無にかかわらず、Dockの実行中インジケータと同じです）。そこへ追加したり、そこから削除したりはできませんが、タイルは**その中でドラッグして並べ替え**られます（ひとつ動かすまではアルファベット順。順序は記憶され、終了してまた起動したアプリでも保たれます。タイルをほかの場所に落とすことはできず、Escまたはほかの場所で放すと元に戻ります。“実行中”を右クリック → **アルファベット順に並べる**で、順序を忘れます）。セクション自体の名前は変更できませんが、見出しをドラッグして（または右クリックメニューの**上へ移動** / **下へ移動**で）カテゴリの間のどこにでも動かせ、隠すこともできます（右クリック → “実行中”を隠す。戻すには、設定 → パネル → “実行中”セクションを表示）。実行中の各アプリの**しまわれたウインドウ**は、そこでそのアプリのタイルに続けて、独立したタイルとして表示できます。角にアプリのアイコンが付いたウインドウの画像と、ウインドウのタイトルです（Dockの表示と同じです）。どれかをクリックするとそのウインドウが戻り、右クリックすると「復元」または「ウインドウを閉じる」が選べます。既定ではオフです。設定 → パネル → “実行中”にしまわれたウインドウを表示をオンにするか、“実行中”を右クリック → しまわれたウインドウを表示を選びます。これらはパネルを開くたびに収集されます（アクセシビリティが必要です。画像には画面収録が必要です）。
- **実行中のアプリのメニュー**：実行中のアプリを右クリックすると、Dockのようなメニューが表示されます。そのウインドウ（前面のものにチェックが付きます。ひとつ選ぶと前面に出ます）、そのファイルメニューの「新規…」コマンド（ブラウザでは新規タブ、新規ウインドウ、新規プライベートウインドウ）、そして**ウインドウを閉じる**（ウインドウが開いているときのみ）、**隠す**、**終了**（Optionを押したままにすると強制終了になります。終了の数秒後もまだ実行中のアプリには、代わりに**強制終了**が表示されます。Dockと同様、Finderには終了がありません。終了するとデスクトップのアイコンが消えるためです）。ウインドウとコマンドは、ポインタがタイルに届いたときにアクセシビリティ経由で読み取られます。
- **ファイルを探す**：書類、デスクトップ、ダウンロードにあるファイルは、HomePadに**フルディスクアクセス**（システム設定 → プライバシーとセキュリティ）が許可されて初めて検索に表示されます。それまでは、結果にスイッチへのリンク付きの通知が表示されます。
- **計算機**：`7+3`、`(2+3)*4`、`2^10`、`15%`のような式を入力すると、答えが最初に表示されます。↩またはコピーボタンでコピーします。
- **ウインドウ**：パネルの任意の端や角をドラッグするとサイズを変更できます（端には幅広のつかみ領域があり、サイズ変更のカーソルが表示されます）。任意の空いている部分をドラッグすると移動できます（タイルのグリッド自体では、ドラッグするとタイルが並べ替えられます）。パネルを開くたびに検索フィールドにフォーカスがあるので、すぐに入力できます。ほかの場所をクリックしたあとは、次に入力するキーが再びそこへ入ります。設定 → パネルには**ウインドウのサイズを記憶**（既定でオン）と**ウインドウの位置を記憶**（既定でオフ）があります。設定の歯車の横の↺ボタンは、パネルを標準のサイズに戻し、中央に配置します。「アプリを追加」と「ファイルまたはフォルダを追加」のウインドウもサイズを変更できます（開くときは常に標準のサイズです）。
- パネルの左下にある**あなたの名前**をクリックすると、システム設定があなたのApple アカウントで開きます。
- **検索**：入力を始めるだけです。最初にアプリ、次に書類とフォルダ、最後にWeb検索が表示されます。↑ ↓で選択、↩で開く、⌘↩でFinderに表示、Escで消去して閉じます。‹ボタンや空いている場所のクリックでも、アプリの表示に戻ります。

## 初回の起動

ようこそウインドウが、画面収録、アクセシビリティ、フルディスクアクセスの許可と、HomePadの開き方の選択を求めます（インストールを参照）。いつでも、メニューバーのアイコン → セットアップガイド…から開き直せます。

## 設定

設定には、ツールバーに6つのタブがあります：**モード**、**一般**（言語、メニューバーのアイコン、ログイン時に開く、デフォルトに戻す、最初からやり直す）、**タスクバー**、**開き方**（ショートカット、ダブルタップ、ホットコーナー）、**パネル**（レイアウト、ウインドウ、項目）、**アクセス権**。最後に使ったタブで開き直します。

- **ショートカット**：ボタンをクリックして、新しい組み合わせを押します。⌘スペースを使うには、先に「システム設定 → キーボード → キーボードショートカット → Spotlight」でSpotlightのショートカットをオフにします。
- **ショートカット**：記録するか、ダブルタップだけにしたい場合は**なし**を選ぶか、**リセット**で⌥スペースに戻します。
- **メニューバーのアイコン**：「設定 → 一般」で隠せます。アプリをもう一度起動すると、パネルが開きます。
- **デフォルトに戻す**：ショートカット、ダブルタップ、レイアウト、Dockを隠す設定、ログイン時に開く設定を元に戻します（アプリとカテゴリは残ります）。
- **ダブルタップ**：Control、Option、Commandのいずれかを2回タップして開きます。
- **1行のアイコン数**（既定は8、4〜10）、**行の高さ**（アイコンの行どうしの距離、既定は101 pt、85〜125）、**アイコンの間隔**（アイコンどうしの横の間隔、既定は10 pt、0〜40。パネルが間隔に対して狭すぎるときは、まず間隔が縮み、次にアイコンが縮みます）：数字を入力するか、− / +をクリックします。**実行中のアプリを表示**、**Dockから再読み込み**。
- **モード**（最初のタブ）：
  - <strong>スタンドアロン</strong>（既定）：ショートカット、ダブルタップ、ホットコーナー、メニューバーのアイコンで開く、浮かぶパネルです。このモードに切り替えるとDockが隠れます。下の<strong>“Dock”を隠す</strong>で元に戻せます。
  - **HomePad + “Dock”**：Dockをタスクバーに見立てた、Windowsのスタートメニューのような使い方です。選ぶと、Dockが常に表示され（自動的に隠す設定は、HomePadのものもシステム設定のものもオフになります）、DockにHomePadがなければ追加されます（Dockは一度再起動します）。Dockは置いた場所のままです。パネルは、アイコンをクリックしてもショートカットやダブルタップを使っても、HomePadのアイコンのすぐ横に開きます（Dockが下なら上に、横なら脇に、画面内に収まるように）。もう一度アイコンをクリックすると閉じます。ホットコーナーは引き続きその角で開きます。HomePadがDockにない、Dockが隠れている、アクセシビリティのアクセス権がない場合に、なぜ中央で開くのかは、設定に説明が表示されます。
  - **タスクバー**：メインの画面の下端に沿った、Windows風のタスクバーです。スタートボタン（HomePadのアイコン）に続いて、ピン留めしたものと実行中のアプリが、中央に並びます。実行中のアプリはパネルから外れます。タスクバーの空いている場所を右クリック（**アプリを追加…**、**ファイルまたはフォルダを追加…**）するか、タイルを右クリック（**タスクバーにピン留め**。HomePadのパネルでも可）して、アプリ、ファイル、フォルダをピン留めします。タスクバーのアイコンのメニューには、HomePad自身のカテゴリ用の**HomePadにピン留め**（またはHomePadからピン留めを外す）もあります。または、FinderやHomePadのパネルからアプリ、ファイル、フォルダをタスクバーへドラッグします。放したアイコンの前に、または空いている場所なら末尾にピン留めされます（すでにピン留めされたものはそこへ移動します。パネルは自分の分を保ちます）。タスクバーのピン留めは独立したリストで、HomePadのカテゴリとは別です。アイコンをタスクバーに沿ってドラッグすると並べ替えられます。**アプリのアイコン**は**中央**または**左**に置きます。中央にあるあいだは、**HomePadのアイコン**はそれらと一緒に中央に置くことも、左に置くこともできます（アプリのアイコンが左なら、HomePadのアイコンは常にそこにあるため、選択肢はグレーになります）。アラビア語とペルシア語では、左は右になり、Windowsと同様に反転します。HomePadのアイコンが左にあるときは、そのパネルはタスクバーの上の左端に開きます。右側には**ネットワーク**、**音量**、**バッテリー**、**時計**があり、それぞれにスイッチがあります。ネットワークとバッテリーはシステム設定でそれぞれのページを開きます（新しいmacOSでは、macOS自身のステータスメニューを外部から開くことはできません）。音量はスライダを開き（その上でスクロールすると音量を変えられます）、時計はカレンダーを開きます。項目をクリックすると、開くか前面に出します（すでに前面なら隠します）。実行中のアプリにポインタを合わせるとウインドウが表示され、右クリックでそのメニューが開きます。設定 → タスクバー → **実行中のアプリ**（最初は折りたたまれています）は、実行中のすべてのアプリを**タスクバーに表示**スイッチ付きで一覧にします。オフにしたアプリは、実行中のあいだタスクバーに出ません（そのメニューの**タスクバーに表示しない**でも可）。ピン留めした項目は常に表示されます。アプリを隠して（Cmd-H）も、タスクバーは変わりません。パネルはタスクバーの上の中央に開きます。その間、Dockは隠れます。macOSでは、画面の一部をウインドウから空けておけるのはDockだけなので、アクセシビリティを使って、ウインドウが開かれたとき、サイズ変更、最大化、タイル表示でタスクバーの下に届くときは、HomePadがそのウインドウを短くします（短くなりすぎる場合は、代わりに上へ移動します）。そこへドラッグしただけのウインドウは、Windowsと同様にそのままにします。（本物のDockをタスクバーの下に残す方法はうまくいきませんでした。ポインタがアイコンの上を通るたびに、名前のラベルを表示してしまうためです。）**タスクバーを自動的に隠す**は、ポインタが下端に**表示までの遅延**のあいだ置かれるまで、タスクバーを画面の下へ滑らせて隠します（0〜1000ミリ秒、既定は300。端をさっと通り過ぎても表示されません）。HomePadのパネル、ポップアップ、ウインドウのプレビュー、メニューが開いているあいだは表示されたままで、その間ウインドウは画面全体を使います。**スタートボタンからのみHomePadを開く**をオンにすると、ショートカット、ダブルタップ、ホットコーナーが無効になります（メニューバーのアイコンは引き続き使えます）。
- **“Dock”を隠す**（スタンドアロンのみ）：Dockの自動的に隠す設定を1000秒の遅延付きでオンにし、Dockが現れないようにします。オフにすると通常のDockに戻ります。
- **ログイン時に開く**。
- **言語**（設定 → 一般、またはメニューバーのアイコンを右クリック → 言語）：Macと同じ、または20言語のひとつ（アラビア語、ベンガル語、中国語（簡体字）、英語、フィリピノ語、フランス語、ドイツ語、ヒンディー語、インドネシア語、イタリア語、日本語、韓国語、ペルシア語、ポルトガル語（ブラジル）、ロシア語、スペイン語、テルグ語、タイ語、トルコ語、ベトナム語）。現在の言語のアルファベット順に並びます。HomePadは新しい言語で再起動します。アラビア語とペルシア語は右から左に表示されます。アプリ、フォルダ、システム設定の各項目の名前は、Macが表示するとおりのままです。

## アクセス権の設定

アクセス権を許可すると（セットアップガイド、設定、ウインドウのプレビューのどこでも）、HomePadはシステム設定でそれがオンになるのを見守り、オンになったらすぐに前面へ戻ります。画面収録とフルディスクアクセスは、通常は再起動が必要です。システム設定が**終了して再度開く**を提示したら、HomePadは終了して自動的に再起動し、あなたがいたウインドウを開き直します。

セットアップガイドが初回起動時に表示されるのは、アクセス権が足りない場合だけです。最初からやり直すには、<strong>設定 → 一般 → 最初からやり直す…</strong>を使います。macOSがHomePadのアクセス権を取り上げ、ガイドが再び表示され、HomePadが再起動します（ボックスにチェックを入れると、新規インストールのように、カテゴリと設定も消去されます）。
